# Partha Sarathy T — Personal Portfolio

A responsive student developer portfolio with project notes, internship
experience, skills, a downloadable A4 resume, and WhatsApp contact.

Built with HTML, CSS, and vanilla JavaScript. No package installation or build
step is required. Assets are served locally with the site.

## Publish on GitHub Pages

In this repository, open Settings → Pages. Select **Deploy from a branch**,
choose **main** and **/(root)**, then save. No custom domain is needed.

The configured website address is https://parthasarathy1111-creator.github.io/personal-portfoilo/
It becomes live after GitHub Pages completes the deployment.

## Files

- `index.html`: portfolio content and social preview metadata.
- `styles.css`: responsive layout and light/dark themes.
- `app.js`: navigation, project filters, theme and clipboard controls.
- `contact.js`: prepares a WhatsApp message for the visitor to send.
- `assets/Partha_Sarathy_Resume_A4.pdf`: the owner's uploaded resume.

Contact messages are reviewed and sent through WhatsApp. The website does not
store messages or claim to have sent them. Resume and images are self-hosted.

[GitHub Pages publishing guide](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
